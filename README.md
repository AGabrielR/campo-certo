# Campo Certo · protótipo

Protótipo de demonstração de gestão de fazenda de gado de corte: pastos e lotes, pesagem com ganho de peso por dia, movimentação do gado, diário com fotos e chuva, tarefas de sanidade e o dinheiro do mês.

A fazenda e os números são fictícios. As fotos foram geradas por IA. Não há servidor: os dados ficam salvos só no aparelho de quem testa.

## Como testar

- **Entrar:** `dono` (vê tudo) ou `capataz` (lança pesagem, movimentação, diário e tarefas, mas não vê o dinheiro). A senha dos dois é `demo`.
- **Ficha do lote para o comprador, sem login:** `?lote=4`. É o link que o dono manda pelo WhatsApp quando vai vender. O sistema não vende gado.
- **Sair ou recomeçar do zero:** botão redondo com as iniciais, no canto de cima.
